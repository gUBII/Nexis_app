CONTX HOW TO RUN (TXT RUNBOOK)
==============================
Project root: /Users/moofasa/Nexis_app

[PREREQUISITES]
- Node.js 18 (recommended)
- npm
- Android Studio + SDK + emulator/device
- Xcode
- Ruby + Bundler + CocoaPods (via ios/Gemfile)

[INSTALL]
1) cd /Users/moofasa/Nexis_app
2) npm install
3) cd ios
4) bundle install
5) bundle exec pod install
6) cd ..

[START METRO]
- npm start

[RUN ANDROID]
- npm run android

[RUN IOS]
- npm run ios
- physical device example:
  npx react-native run-ios --device "Farhan’s iPhone"

[IOS REQUIRED NOTES]
- Use a unique bundle id in Xcode Signing.
- Add ios/app/GoogleService-Info.plist to enable Firebase default app on iOS.
- If "No permission handler detected":
  - reinstall pods
  - clear DerivedData
  - uninstall/reinstall app

[CLEAN]
Android:
- cd android && ./gradlew clean && cd ..

iOS:
- rm -rf ~/Library/Developer/Xcode/DerivedData
- cd ios && rm -rf Pods Podfile.lock && bundle exec pod install && cd ..
